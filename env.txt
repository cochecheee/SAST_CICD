  Tổng quan — dịch vụ free để test                                                                                        
                                                                                                                        
  ┌─────────────────────────────────────────┬────────────────┬──────────────────────────────────────┐
  │                 Secret                  │  Dùng dịch vụ  │               Mục đích               │
  ├─────────────────────────────────────────┼────────────────┼──────────────────────────────────────┤
  │ DASHBOARD_WEBHOOK_URL + DASHBOARD_TOKEN │ webhook.site   │ Xem payload JSON pipeline gửi lên    │
  ├─────────────────────────────────────────┼────────────────┼──────────────────────────────────────┤
  │ SMTP_* + EMAIL_*                        │ Mailtrap.io    │ Nhận email HTML test, không gửi thật │
  ├─────────────────────────────────────────┼────────────────┼──────────────────────────────────────┤
  │ SONAR_*                                 │ sonarcloud.io  │ Phân tích code                       │
  ├─────────────────────────────────────────┼────────────────┼──────────────────────────────────────┤
  │ DOCKER_*                                │ hub.docker.com │ Build & push image                   │
  ├─────────────────────────────────────────┼────────────────┼──────────────────────────────────────┤
  │ NVD_API_KEY                             │ nvd.nist.gov   │ CVE database                         │
  └─────────────────────────────────────────┴────────────────┴──────────────────────────────────────┘

  ---
  Bước 1 — webhook.site (thay Dashboard)

  1. Vào https://webhook.site → trang load xong là có ngay một URL unique, ví dụ:
  https://webhook.site/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
  2. Copy URL đó — đây chính là DASHBOARD_WEBHOOK_URL
  3. DASHBOARD_TOKEN để bất kỳ chuỗi nào (webhook.site không check token):
  test-token-123
  4. Sau khi pipeline chạy, quay lại webhook.site để thấy toàn bộ JSON payload

  ---
  Bước 2 — Mailtrap.io (thay SMTP thật)

  1. Vào https://mailtrap.io → Sign up free
  2. Vào Email Testing → Inboxes → My Inbox → SMTP Settings
  3. Chọn tab "Other" — sẽ thấy:
  Host: sandbox.smtp.mailtrap.io
  Port: 587
  Username: xxxxxxxxxxxxxxxx
  Password: xxxxxxxxxxxxxxxx
  4. Dùng các giá trị đó cho secrets bên dưới

  ---
  Bước 3 — Thêm tất cả secrets vào GitHub

  Chạy từng lệnh (thay giá trị thật vào):

  cd D:/School/nam4-ky1/tlcn/ALOUTE_Spring_Thymeleaf_RCE

  # ── DASHBOARD (webhook.site) ────────────────────────────────────────────────
  gh secret set DASHBOARD_WEBHOOK_URL --body "https://webhook.site/YOUR-UUID-HERE"
  gh secret set DASHBOARD_TOKEN       --body "test-token-123"

  # ── EMAIL (Mailtrap) ────────────────────────────────────────────────────────
  gh secret set SMTP_HOST  --body "sandbox.smtp.mailtrap.io"
  gh secret set SMTP_PORT  --body "587"
  gh secret set SMTP_USER  --body "YOUR_MAILTRAP_USERNAME"
  gh secret set SMTP_PASS  --body "YOUR_MAILTRAP_PASSWORD"
  gh secret set EMAIL_FROM --body "ci-pipeline@test.com"
  gh secret set EMAIL_TO   --body "your-email@example.com"

  # ── SONARCLOUD ───────────────────────────────────────────────────────────────
  gh secret set SONAR_TOKEN        --body "squ_xxxxxxxxxxxx"
  gh secret set SONAR_ORGANIZATION --body "your-org-key"
  gh secret set SONAR_PROJECT_KEY  --body "your-org_aloute-spring"

  # ── DOCKER HUB ───────────────────────────────────────────────────────────────
  gh secret set DOCKER_USERNAME --body "yourdockerhubuser"
  gh secret set DOCKER_PASSWORD --body "dckr_pat_xxxxxxxxxxxx"

  # ── NVD ─────────────────────────────────────────────────────────────────────
  gh secret set NVD_API_KEY --body "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"

  Kiểm tra đã set đủ chưa:
  gh secret list

  ---
  Bước 4 — Trigger pipeline và quan sát

  git add -A && git commit -m "test: trigger CI pipeline" && git push origin main

  Sau đó:
  - GitHub Actions: https://github.com/YOUR-REPO/actions — xem từng job
  - webhook.site: thấy JSON payload với status, gate1, by_severity
  - Mailtrap inbox: thấy email HTML với bảng severity + critical findings
